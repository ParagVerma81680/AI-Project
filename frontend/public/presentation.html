03 / PROBLEM STATEMENT

Physical Retail Friction vs. SmartMart Transformation

❌ Traditional Retail Inefficiencies

  • Aisle Disorientation: Shoppers waste 40% of their total store time retracing paths across distant aisles.
  • Policy Misinformation: Clerks misquote return policies (e.g. 14 vs 30 days) or perishables rules, causing disputes.
  • Disconnected Stock: Customer inquiries at customer service cannot verify live shelf aisle placement in real time.
  • Generic Offers: Store discounts lack personalized dietary, allergy, or budget context.

✅ SmartMart Autonomous Solutions

  • Dijkstra + TSP Pathfinding: Mathematically orders shopping items into the shortest continuous route, reducing walking by 42%.
  • Policy RAG System: Instant answers grounded in official store policies with cited source sections and thermal receipt proof.
  • Unified Database: Real-time SQLite catalog guarantees zero inventory discrepancy between shelf and screen.
  • Personalized Bundling: AI synthesizes tailored item bundles respecting vegetarian, vegan, and budget constraints.

08 / AI TECHNOLOGIES

4-Paradigm AI Architectural Comparison

⚙️

1. Rule-Based

0 AI Calls · Deterministic

Keyword matching against fixed policy regex. Ultra fast (<5ms) but fails completely on semantic paraphrasing.

🧠

2. Zero-Shot LLM

1 LLM Call · Un-grounded

Direct prompt to foundation model. Fluent language generation, but fabricates store return timelines.

📚

3. Policy RAG

1 TF-IDF + 1 LLM Call

Retrieves exact policy excerpts before generation. 100% grounded answers with thermal receipt proof.

🤖

4. Multi-Agent

3 Collaborative Calls

Customer Agent synthesizes intent; Store Agent executes live SQL verification. Highest quality consensus.

  2. List Curation: Selects items or loads one-click sample carts (e.g. "Breakfast Essentials").

12 / DATA MANAGEMENT

Relational Schema & Dynamic State Lifecycle

Products Entity

Table: products - id: INTEGER (PK) - name: VARCHAR(100) - price: FLOAT - category_id: INTEGER (FK) - aisle: VARCHAR(10) [A1-D1] - stock_quantity: INTEGER - is_in_stock: BOOLEAN

Store Graph Entity

Graph: STORE_GRAPH - Nodes: ['ENTRANCE', 'A1', 'A2', 'B1', 'B2', 'C1', 'C2', 'D1', 'EXIT'] - Edges: Undirected weighted - Weights: Metric distances between physical gondolas

Policies Knowledge

Table: policies - id: INTEGER (PK) - category: VARCHAR(50) - title: VARCHAR(150) - body_text: TEXT - return_window_days: INT - requires_receipt: BOOL

Persistence Guarantees: SQLite relational engine handles ACID-compliant updates from the Admin portal. Frontend client synchronizes through localStorage caching, maintaining seamless state on static hosting.

16 / ACADEMIC TRANSPARENCY

Current System Constraints & Scope Boundaries

Static Hosting Boundaries

GitHub Pages is purely static. Without local Python server running, live AI falls back to in-browser Groq API key or mock data.

TF-IDF vs Dense Vectors

Policy retrieval uses lexical TF-IDF scoring rather than dense neural embeddings (FAISS/Milvus), limiting cross-language synonym matching.

Single-Floor Graph

The store layout models 8 aisles across a single planar level; multi-floor elevator/escalator routing is not yet implemented.

SQLite Concurrency

SQLite is ideal for collegiate demonstration but would require migration to PostgreSQL for hundreds of concurrent cashier writes.

Simulated IoT Sensors

SmartCart tare weight scale and RFID gates are functionally simulated in software rather than interfaced to physical microcontrollers.

Offline Voice Input

Walkie-talkie dialog currently runs via text tokens; full Speech-to-Text (Whisper) streaming is slated for next phase.
